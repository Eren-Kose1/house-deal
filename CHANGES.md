# Changes

## v3 (28 Oct 2026)

Changes from user testing at the Week 5 maker fair; [TESTING.md](TESTING.md) maps each one to the feedback.

- Chores are checklists; other people's missing steps are visible.
- Undo a done chore any time that week.
- Reminder banner while your own chore is open.
- Past weeks view (last three weeks).
- Supplies tab: one "I bought it" completes an item for everyone.
- Rules: a no or a tweak puts a proposal in revision until all four agree; "Suggest a middle ground" starts a new round; your own proposals can be withdrawn.
- Named comments under every rule.
- Invite a flatmate with a QR code; new flatmates go through the rules and say OK or ask.
- "Done this month" is now counted from the chore records.
- Saved demo data from v2 is reset on first load, because the data format changed.

## v2 (26 Oct 2026)

First build for the shared-housing domain: chore rota, kind nudges, house rules with OK / Tweak / No, and two-week check-ins.
